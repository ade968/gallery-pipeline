02

Phase 1: Benchmarking & Model Selection

This is a pure development-stage sandbox to evaluate which AI model writes the best visual prose and metadata for your photos.

  1. 1.1 Define Test Suite: We select a fixed test set of 3–4 images (e.g., the Jasmine photos and landscape tests).
  2. 1.2 Audition Models: We feed these images to 3 different models (e.g., Claude 3.5 Sonnet, Gemini 1.5 Pro, and Claude 3.5 Haiku).
  3. 1.3 Evaluate Sidecars: The pipeline generates comparison sidecars side-by-side in your working folder so you can review their descriptions and pick our preferred runtime champion.
03

Phase 2: UI Sandbox & Auditioning Design Skills

Before writing the pipeline's publishing code, we will explore the visual container of your photography, focusing on typographic layout.

  1. 2.1 Audition Design Skills: We will review and test specialized design skills to find the best layouts.
  2. 2.2 The Typography Sandbox: Build a local static prototyping page using dummy photos/text. We will use this to test Carson-inspired "Expressive Editorial" layouts.
  3. 2.3 Screen-size Exploration: Test how overlapping headers, dramatic text scales, and asymmetrical grids translate cleanly to mobile screens vs. desktop.

05

Phase 4: Comparative Narratives & Groups

Bringing in the human-AI collaborative curation features.

  1. 4.1 Gallery-Level Markdown: Create a template for group-level narratives where you write your curator statement.
  2. 4.2 "Polly Perspective" Generation: Implement multi-voice AI responses driven by specific moods/personas matching the gallery's theme.
  3. 4.3 Side-by-Side Display: Render your narrative next to the multiple AI voices on the web index.
06

Phase 5: Baseline UI & Deployment

Bringing the complete project live.

  1. 5.1 Grid Base-Design: Implement a clean, responsive thumbnail grid of your photography where each image can be clicked to fill the browser window.
  2. 5.2 Git & Vercel Pipeline: Set up the repository structure to push to GitHub, letting Vercel auto-deploy the static build on push.
  3. 5.3 Post-MVP (Full Chaos): Plan the step-up to a more extreme David Carson-inspired layout as a secondary style option.
